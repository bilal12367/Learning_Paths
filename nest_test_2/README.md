# Guide to run this nest application

## Prerequisites

1. Vagrant must be installed.
2. node 18

## Guide

1. Start Machine by using vagrant up command
2. Once the machine is up, it will automatically start the container.
3. Configure the url to connect to db in
 ```nest_test_2\src\config\MySqlConfig.ts```
4. Once, the db is connected you can hit the api and start playing with the application.
